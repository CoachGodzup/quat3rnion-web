# Regole del repo Quat3rnion Web

## Documentazione condivisa

- La documentazione del progetto Quat3rnion vive nel repo principale
  `quat3rnion` (privato), nella cartella `docs/`: è la **fonte unica di
  verità**. Questo repo non la duplica.
- Per architettura, regole di gioco, formato livelli, UI e glossario fai
  riferimento a `../quat3rnion/docs/` (o al repo principale su GitHub).
- Se un documento deve essere pubblicato anche qui, copialo dal repo
  principale senza riscriverlo e mantienilo allineato; le modifiche di merito
  si fanno prima in `quat3rnion/docs/`.
- Non creare documentazione fuori dal README o da `docs/` sincronizzata: niente
  file di note sparsi nella radice.
