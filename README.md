# Quat3rnion — prototipo web

Prototipo giocabile (Three.js) del puzzle **Quat3rnion**.

- Sito: <https://coachgodzup.github.io/quat3rnion-web/>
- Logica: port fedele della core logic originale; livelli in XML.
- Comandi: click su una stanza per muovere; `1`–`6` facce, `7`–`=` colonne
  (prima pressione = anteprima freccia/spirale, seconda = esegue);
  `[` `]` cambia livello; `R` ricarica; trascina per orbitare.

Sorgente e materiale di recupero nel repo principale (privato).
