# Quat3rnion — prototipo web

Prototipo giocabile (Three.js) del puzzle **Quat3rnion**.

- Sito: <https://coachgodzup.github.io/quat3rnion-web/>
- Logica: port fedele della core logic originale; livelli in XML.
- Comandi: click su una stanza per muovere; `WASD` / `QE` per muoversi,
  `Tab` cambia Cub1X, `1`–`6` ruotano le facce, `9` / `0` le colonne verticali,
  `[` `]` cambiano livello, `R` ricarica; trascina per orbitare.
- In alto a destra: selezione livello, pulsanti di gioco e **level editor**.
  In basso: controlli di rotazione.
- A fine partita compare un messaggio a tutto schermo: `YOU WIN` o `YOU LOSE`.

Sorgente e materiale di recupero nel repo principale (privato).
